# LoadMaster

Откройте Home.html (или index.html) в браузере. Сборка и интернет не нужны.

В комплекте Home.html, Privacy.html, Terms.html, Refund.html, общий styles.css/app.js, локальные шрифты, иллюстрация, фотографии для карточек ролей и главный экран приложения.

Функции сверены по 26 скриншотам. См. FEATURE-AUDIT.md: охват модулей, источники и оставшиеся вопросы. В разделе Android показан один главный экран приложения с демонстрационным названием компании. На сайте доступны раскрытие деталей модулей, интерактивные этапы, FAQ и мобильное меню.

Terms.html, Privacy.html и Refund.html содержат полные тексты клиента без изменения формулировок. Исходные названия, реквизиты, email и поля для даты/контакта сохранены как в предоставленных TXT.

Кнопки Download app скачивают downloads/LoadMaster.apk — APK, предоставленный для этого проекта. Сохраняйте папку downloads рядом с HTML при размещении сайта.
